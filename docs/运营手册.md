# CoolFly 官网运营手册

这份手册写给负责网站日常运营和广告投放的同事。读完以后，你可以自己完成发新闻、改首页、做投放落地页、接入广告追踪和接收询盘，不需要找开发。

---

## 1. 网站是怎么更新的

```
在后台修改内容 → 点保存 → 网站自动重新发布（约 1–2 分钟）→ 线上看到新内容
```

- 后台地址：**https://app.pagescms.org**
- 你用**邮箱**登录，不需要 GitHub 账号。
- 每次保存都有历史记录。改错了，可以让管理员恢复到之前的版本。
- 后台只能改内容（文字、图片、参数、开关），不能改版式。所以不用担心把网站排版弄乱。

## 2. 第一次登录

**管理员（只需做一次）：**

1. 用 GitHub 账号登录 https://app.pagescms.org
2. 按提示安装 Pages CMS 的 GitHub App，并允许它访问 `AlexDY0991/coolfly-site` 这个仓库。
3. 打开这个仓库，在协作者（Collaborators）设置里输入运营同事的邮箱，发送邀请。具体按钮名称以界面为准。

**运营同事：**

1. 打开邀请邮件里的链接，用邮箱登录。
2. 左侧会看到四组菜单：**日常运营**、**网站内容**、**中文站**、**设置**。前两组是英文站，「中文站」是 coolflyaircraft.net 的内容。

## 4. 常见操作

### 4.1 发一篇新闻

1. **日常运营 → 新闻与文章 → 新建**
2. 填写**标题**、**发布日期**、**分类**（新闻 / 活动与展会 / 科普与观点）。
3. **摘要**写一两句话。它会显示在新闻列表和 Google 搜索结果里。
4. 上传**封面图**，并填写**封面图描述**（用一句英文描述图片内容）。
5. 在**正文**里写内容，可以插入图片、加粗、插入链接、添加小标题。
6. 确认**已发布**是打开状态，然后保存。

文章地址是 `/news/文章网址.html`。新建时系统会按标题自动生成网址，你也可以手动修改：只能用小写英文和连字符，尽量简短。

> 想先存草稿：把**已发布**关掉再保存，网站上就不会显示这篇文章。

### 4.2 做一个投放落地页

落地页是专门给广告用的页面：只讲一件事，只放一个表单，转化率比把广告直接导到首页高。

1. **日常运营 → 投放落地页**，打开示例「Dealer recruitment (worldwide)」作为参考。
2. 点**新建**，依次填写：
   - **内部名称**：只有后台能看到，例如「欧洲经销商 - Google Ads - 2026Q4」。
   - **网址**：例如 `dealer-europe`，页面地址就是 `/lp/dealer-europe.html`。
   - **主标题 / 副标题 / 主图**：和广告文案保持一致，转化效果更好。
   - **卖点**：建议 3 条，每条一句话。
   - **展示机型**：选择要展示的产品。
   - **表单类型**：经销商申请，或预约试飞。
   - **不让搜索引擎收录**：只用来投广告的页面，建议保持打开。
   - **隐藏网站导航**：建议打开，访客更不容易离开页面。
3. 保存，1–2 分钟后就可以把网址填进广告后台。

每一份询盘都会自动记录来自哪个落地页（字段 `form_source`，例如 `lp:dealer-europe`），方便比较不同广告的效果。

### 4.3 修改首页

**网站内容 → 首页**。页面从上到下的各个区域，在后台都有对应的分组：首屏、主张与数字、全屏大图、双图、安全区、应用场景、执照说明条、展会照片带，以及橙色经销商招募条（这条全站通用）。

### 4.4 修改产品参数

**网站内容 → 产品 → 选择机型**。可以修改文案、图片、关键数字、产品特点、安全配置、参数表和认证文件。

- 产品不能在后台新建或删除。新增机型需要开发配合。
- **内部备注**里记录了需要核实的数据，访客看不到。

### 4.5 调整经销商招募弹窗

**设置 → 网站设置 → 经销商招募弹窗**

- **启用**：总开关。
- **停留多少秒后弹出 / 滚动到多少百分比时弹出**：两个条件满足任意一个就会弹出。
- **同一访客多少天内只弹一次**：默认 7 天。
- 标题、说明、图片、按钮文字都可以改。

经销商页、联系页和落地页本身就有表单，这些页面不会弹出。

## 5. 图片规范

| 用途 | 建议尺寸 | 格式 |
|---|---|---|
| 首屏和页面主图 | 1920 × 1080 | JPG |
| 新闻封面 | 1600 × 1000 | JPG |
| 产品图（透明背景） | 1600 宽 | PNG 或 WebP |
| 分享图片 | 1200 × 630 | JPG |

- 文件名请用英文，例如 `ifa-2026-booth.jpg`。
- 超过 2000 像素宽或大于 600 KB 的图片，网站发布时会自动压缩。即便如此，上传前尽量控制在 1 MB 以内，后台上传会更快。
- 每张图都填一句描述（Alt）。这对 Google 图片搜索和视障用户都有帮助。

## 6. 广告追踪：GA4、Google Ads、Meta、TikTok、LinkedIn

网站只需要接入一个 **Google Tag Manager（GTM）**。其他所有平台的代码都在 GTM 里添加，不需要改网站。

### 6.1 接入 GTM（只做一次）

1. 在 https://tagmanager.google.com 创建账号，容器类型选择「网站」。
2. 复制容器 ID（格式为 `GTM-XXXXXXX`）。
3. 打开后台 **设置 → 网站设置 → 追踪代码**，粘贴后保存。

### 6.2 网站已经自动发送的事件

GTM 里可以直接用「自定义事件」触发器捕捉下面这些事件：

| 事件名 | 什么时候发送 | 附带信息 |
|---|---|---|
| `generate_lead` | 询盘**提交成功** | `form_name`（dealer / contact）、`form_source`（来自哪个页面或落地页）、`aircraft` |
| `form_start` | 访客开始填写表单 | `form_name`、`form_source` |
| `form_error` | 提交失败 | `form_name`、`error` |
| `cta_click` | 点击主要按钮（成为经销商、预约试飞、查找经销商等） | `cta_name`、`cta_text`、`link_url` |
| `email_click` | 点击邮箱地址 | `link_url` |
| `popup_open` / `popup_close` | 招募弹窗打开 / 关闭 | `popup_name` |
| `consent_update` | 访客在 Cookie 横幅里做出选择 | `consent`（granted / denied） |

另外，询盘提交成功后会跳转到感谢页 `thanks.html`。各广告平台也可以用「访问感谢页」作为转化条件。

### 6.3 各平台怎么配置（都在 GTM 里完成）

| 平台 | 在 GTM 里添加的代码 | 触发条件 | 转化事件 |
|---|---|---|---|
| **GA4** | Google 代码（填 `G-` 开头的衡量 ID） | 所有页面 | 再加一个 GA4 事件代码：事件名 `generate_lead`，触发条件是自定义事件 `generate_lead`。然后在 GA4 后台把它标记为关键事件 |
| **Google Ads** | 转化链接器（Conversion Linker）+ Google Ads 转化跟踪 | 转化链接器：所有页面。转化跟踪：自定义事件 `generate_lead` | 在 Google Ads 后台新建「提交潜在客户表单」类型的转化 |
| **Meta（Facebook / Instagram）** | 从 GTM 模板库添加 Meta Pixel 模板 | PageView：所有页面。Lead：自定义事件 `generate_lead` | Lead |
| **TikTok** | 从 GTM 模板库添加 TikTok Pixel 模板 | 页面浏览：所有页面。转化：自定义事件 `generate_lead` | 选择提交表单类的标准事件 |
| **LinkedIn** | LinkedIn Insight Tag（GTM 内置模板，填 Partner ID） | 所有页面 | 在 LinkedIn Campaign Manager 新建转化，条件设为访问的网址包含 `thanks.html` |

每添加完一个代码，用 GTM 的「预览」模式打开网站，提交一次测试询盘，确认代码被触发后再点「提交」发布。

### 6.4 Cookie 同意（欧洲必需）

- 网站已内置 Cookie 同意横幅，并接入了 **Google Consent Mode v2**。
- 欧洲（欧盟、英国、瑞士）的访客，在点击「Accept」之前，统计和广告代码不会记录个人数据。其他地区默认记录，访客也可以选择拒绝。
- Google 的代码（GA4、Google Ads）会自动遵守访客的选择。
- **Meta、TikTok、LinkedIn 的代码需要你在 GTM 里手动设置**：打开代码的「高级设置 → 同意设置」，选择「需要额外同意」，并勾选 `ad_storage`。

### 6.5 广告链接的 UTM 命名

每个广告链接都要带上 UTM 参数，询盘里会自动记录这些信息：

```
https://coolflyaircraft.com/lp/dealer-europe.html?utm_source=google&utm_medium=cpc&utm_campaign=dealer-eu-2026q4&utm_content=video-a
```

| 参数 | 含义 | 建议取值 |
|---|---|---|
| `utm_source` | 渠道 | google / meta / tiktok / linkedin / newsletter |
| `utm_medium` | 类型 | cpc（付费点击）/ paid-social / email / organic-social |
| `utm_campaign` | 活动 | 用途-地区-时间，例如 `dealer-eu-2026q4` |
| `utm_content` | 素材 | 区分不同的广告素材，例如 `video-a`、`image-b` |

各平台的点击 ID（Google 的 `gclid`、Meta 的 `fbclid`、TikTok 的 `ttclid`、LinkedIn 的 `li_fat_id`）也会自动记录，不需要手动添加。

## 7. 询盘接收

打开**设置 → 网站设置 → 表单接收**，在「询盘发送到」里选择一种方式：

- **暂不接收**：访客提交表单时，网站会提示对方直接发邮件。这是目前的状态。
- **HubSpot**（推荐，免费版就够用）：
  1. 在 HubSpot 里新建两个表单：「经销商申请」和「联系我们」。
  2. 两个表单都要包含这些字段：`firstname`、`lastname`、`email`、`phone`、`company`、`website`、`country`、`jobtitle`、`message`。
  3. 把 Portal ID 和两个表单的 ID 填进后台。
  4. 网站上的其他信息（意向区域、机型、广告来源等）会自动写进 `message` 字段。
- **Webhook**：适用于 Zapier、Make、飞书多维表格、Formspree 等工具。网站会把完整询盘以 JSON 格式发送到你填写的地址，包含：所有表单字段、`form`、`form_source`、`page`、`utm_*`、各平台点击 ID、`landing_page`、`referrer`。

接好后请提交一次测试询盘，确认在 HubSpot 或表格里能收到。

1. Urban 的最大起飞重量：旧官网写的是 254 kg，很可能应该是 254 lb，目前网站上没有显示这一项。

## 12. 中英文双站与域名

**对外只需要公布 coolflyaircraft.com 一个网址。**

| | 英文站 | 中文站 |
|---|---|---|
| 域名 | coolflyaircraft.com | coolflyaircraft.net |
| 托管 | Cloudflare Pages（海外快） | 阿里云 OSS + CDN（国内快） |
| 后台 | 同一个 Pages CMS，左侧「中文站」菜单编辑中文内容 | |
| 追踪 | GTM（GA4、Google Ads、Meta、TikTok、LinkedIn） | 百度统计（国内打不开 Google） |

### 12.1 访客会看到哪个版本

- 中国大陆的访客打开 .com，会自动跳转到 .net 的同一页面（中文版）。首次访问多一次跳转，大约 1–2 秒。
- 其他地区的访客打开 .com，直接看到英文版。
- 每页右上角都有 **中文 / EN** 切换。手动选过语言后，网站会记住，之后不再自动跳转。
- 浏览器语言和当前网站不一致时，右上角会出现一次「This site is also available in English / 中文版网站」提示，不会强制跳转。
- 搜索引擎爬虫不跳转；两个版本之间有 hreflang 标注，Google 会给英文用户显示 .com，百度显示 .net。
- 新闻两边各自独立：英文新闻只在 .com，中文新闻只在 .net。在新闻页切换语言会回到另一个语言的新闻中心。

### 12.2 一次性设置（技术同事）

**第一步：Cloudflare（.com）**

1. 把 coolflyaircraft.com 的 DNS 迁到 Cloudflare。注意保留阿里云企业邮箱的 MX 记录（mx1/mx2/mx3.qiye.aliyun.com）和 TXT 记录，否则邮箱会收不到信。
2. Cloudflare Pages 连接仓库，构建命令 `npm run build`，环境变量 `SITE_LANG=en`，输出目录 `dist`，绑定 coolflyaircraft.com。
3. Rules → Redirect Rules → 新建规则「中国大陆访客去中文站」：
   - 条件（Edit expression）：
     ```
     (ip.src.country eq "CN") and not (http.cookie contains "coolfly_lang=en") and not (http.request.uri.query contains "lang=en") and not cf.client.bot
     ```
   - 动作：Dynamic，表达式 `concat("https://coolflyaircraft.net", http.request.uri.path)`，状态码 **302**，勾选保留查询参数（广告的 UTM 参数会一起带过去）。
   - 用 302 而不是 301，浏览器不会永久缓存跳转，用户手动选英文后可以正常访问。

**第二步：阿里云（.net）**

1. 新建 OSS Bucket（例如 coolfly-net，华东 1 杭州），开启「静态页面」：默认首页 `index.html`，默认 404 页 `404.html`。
2. CDN 添加加速域名 coolflyaircraft.net，源站选这个 Bucket，配置 HTTPS 证书。缓存规则：`.html` 不缓存或缓存 1 分钟，图片、CSS、JS 缓存 30 天。
3. 在阿里云 RAM 新建一个只能写这个 Bucket 的子账号，生成 AccessKey。
4. 在 GitHub 仓库 Settings → Secrets and variables → Actions 添加：`ALIYUN_ACCESS_KEY_ID`、`ALIYUN_ACCESS_KEY_SECRET`、`ALIYUN_OSS_BUCKET`、`ALIYUN_OSS_ENDPOINT`（例如 `oss-cn-hangzhou.aliyuncs.com`）。
5. 之后每次在后台保存，`Deploy Chinese site to Alibaba Cloud` 会自动构建中文站并上传，和英文站同步更新。
6. 把 .net 的解析从旧 WordPress 切到新的 CDN 地址。切换前先确认旧站的文章都已导入（已导入 55 篇）。
7. 旧中文站文章的网址在 OSS「静态页面 → 重定向规则」里配置跳转（清单在构建产物 `dist/_redirects`，用 `SITE_LANG=zh npm run build` 生成）。

**海外访客打开 .net：** 默认看到中文版，右上角会提示切换英文。如需强制跳转到 .com，可在阿里云 CDN 用 EdgeScript 按国家跳转，一般不需要，因为对外只公布 .com。

### 12.3 以后升级（方案 A，可选）

如果 .com 完成 ICP 备案，可以改为在阿里云云解析按线路解析：国内线路指向阿里云 CDN，海外线路指向 Cloudflare。这样国内访客打开 .com 不需要跳转，地址栏也一直是 .com。网站代码不需要改。

### 12.4 中文站追踪

- 国内无法加载 Google 的代码，中文站请使用 **百度统计**：在 tongji.baidu.com 新建站点 coolflyaircraft.net，复制代码里 `hm.js?` 后面的 32 位字符，填到「中文站 → 中文站设置 → 百度统计 ID」。
- 网站已有的事件（表单提交、按钮点击、弹窗等）会同时发送到百度统计的「事件分析」。
- 中文站的询盘和英文站走同一个表单接收设置（「设置 → 网站设置 → 表单接收」）。如果用 HubSpot，国内访客可能提交失败，建议改用 Webhook（如飞书、企业微信机器人或 Make）。
